# مشروع الكشف عن الحريق (Fire Detection)

## المشكلة التي تم حلها
كان الكود يفشل في فتح الكاميرا على ويندوز بسبب backend الـ MSMF:
```
OnReadSample() is called with error status: -1072875772
can't grab frame. Error: -1072875772
```
تم الحل باستخدام backend الـ **DirectShow** بدلًا منه، وهو أكثر استقرارًا لكاميرات اللابتوب على ويندوز:
```python
cap = cv2.VideoCapture(0, cv2.CAP_DSHOW)
```

## محتويات المشروع
```
Fire/
├── main.py              # الكود الرئيسي (تم إصلاحه)
├── fire_detection.xml   # ملف Haar Cascade للكشف عن الحريق (يجب أن يكون موجودًا لديك)
├── audio.wav            # ملف صوت الإنذار (يجب أن يكون موجودًا لديك)
├── requirements.txt     # المكتبات المطلوبة
└── README.md
```

⚠️ **ملاحظة مهمة**: ملفي `fire_detection.xml` و `audio.wav` لم يتم إنشاؤهما هنا لأنهما موجودان بالفعل عندك في المجلد (كما يظهر في مشروعك الأصلي). ضع نسخة `main.py` الجديد في نفس المجلد الذي يحتوي عليهما.

## التثبيت
```bash
pip install -r requirements.txt
```

## التشغيل
```bash
python main.py
```

## أهم التحسينات في main.py
1. **إصلاح الكاميرا**: استخدام `cv2.CAP_DSHOW` لفتح كاميرا اللابتوب بشكل صحيح.
2. **فحص الملفات قبل التشغيل**: يتأكد الكود من وجود `fire_detection.xml` و `audio.wav` قبل البدء، ويعطي رسالة خطأ واضحة لو ناقصين.
3. **فحص صلاحية ملف الكشف**: التأكد أن `fire_detection.xml` تم تحميله بنجاح (`cascade.empty()`).
4. **تحديد مكان الحريق بوضوح**: رسم مربع أحمر + كتابة "Fire Detected" فوق كل منطقة مكتشفة.
5. **صوت إنذار مستمر أثناء وجود الحريق**: تمت إضافة `SND_LOOP` بحيث يتكرر الصوت طالما الحريق مستمر في الظهور، ويتوقف تلقائيًا فور اختفائه.
6. **رسائل توضيحية بالعربي** في الطرفية (Terminal) لمتابعة حالة النظام.

## استكشاف الأخطاء
| المشكلة | الحل |
|---|---|
| الكاميرا لا تفتح | أغلق أي برنامج آخر يستخدمها (Zoom, Teams...) |
| نفس خطأ MSMF ما زال يظهر | جرب `cv2.VideoCapture(1, cv2.CAP_DSHOW)` لو عندك أكثر من كاميرا |
| الصوت لا يعمل | تأكد أن `audio.wav` بصيغة WAV فعلية (وليس MP3 بامتداد wav) |
| كشف كاذب كثير | ارفع قيمة `MIN_NEIGHBORS` في أعلى الملف (مثلاً من 3 إلى 5) |
